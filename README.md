# XcleaControl — iOS приложение для управления роботом пылесоса Xclea H30

> **Важно**: Этот проект содержит UI и архитектуру приложения. Слой обмена данными с устройством пока пустой (заглушка). Для реальной работы нужно реализовать протокол общения с пылесосом, либо использовать локальную сеть.

## Структура проекта

```
XcleaControl/
├── XcleaControlApp.swift          # Точка входа
├── Models/
│   ├── Device.swift                 # Модель устройства
│   ├── VacuumState.swift            # Состояние пылесоса
│   └── ProtocolMessage.swift        # Формат сообщений
├── Services/
│   ├── DeviceDiscoveryService.swift # Поиск устройства в сети
│   ├── ConnectionService.swift      # Управление соединением
│   ├── ProtocolService.swift        # Логика обмена сообщениями
│   └── StorageService.swift         # Локальное хранилище настроек
├── Views/
│   ├── MainView.swift               # Главный экран
│   ├── DeviceListView.swift         # Список устройств
│   ├── DeviceDetailView.swift       # Детали устройства
│   ├── ControlView.swift            # Управление (начать/остановить)
│   ├── StatusView.swift             # Статус устройства
│   ├── ScheduleView.swift           # Расписание
│   ├── MapView.swift                # Карта (заглушка)
│   └── SettingsView.swift           # Настройки
├── Utilities/
│   └── Extensions.swift
└── Resources/
    └── Info.plist
```

## Фичи приложения

- 🔍 **Поиск устройства** в локальной сети (mDNS / IP-скан)
- 📶 **Отображение статуса**: заряд, режим, местоположение, ошибка
- 🎮 **Управление**: начать, остановить, приостановить, вернуться на заряд
- 📅 **Расписание** (заглушка)
- 🗺 **Карта** (заглушка)
- ⚙️ **Настройки** подключения

## Как запустить

1. Откройте проект в Xcode (Mac)
2. Выберите целевой iPhone
3. Нажмите ▶️ для сборки
4. Приложение запустится на устройстве

## Для разработки

В режиме отладки приложение может работать в "самодежном" режиме:
- Подключает виртуальное устройство (мок)
- Позволяет протестировать UI
