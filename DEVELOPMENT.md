## 🔧 Инструменты для анализа протокола

### Wireshark (аналог tcpdump)
- Отслеживать сетевой трафик
- Просматривать пакеты Wi-Fi
- Определять формат сообщений

### Установка Wireshark:
```bash
brew install wireshark
```

### Доступ к сети:
- Подключите телефон и роутер в режиме мониторинга
- Словарики Wi-Fi (IDB, A-MPDU)
- Фильтр пакетов для вашего IP

## 📐 Примерный формат протокола

Предположим, что устройство использует TCP или UDP. Примерный формат:

```
REQUEST: { "msg_id": "uuid", "cmd": "start", "params": {} }
RESPONSE: { "msg_id": "uuid", "status": "ok", "data": {...} }
```

## ⚠️ ПРЕДУПРЕЖДЕНИЯ

1. **Облачные серверы Huawei не работают** — приложение не будет работать через облако
2. **Устройство использует локальную сеть** — убедитесь, что вы подключены к одной сети
3. **Сервер на роутере (облако) может быть сломан** — иногда можно восстановить общение через локальную сеть
4. **Не пользуйтесь нелегально** — относитесь к коду честно, используйте для личных нужд
